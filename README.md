# Portfólio — Danilo Fiod

Portfólio profissional de Danilo de Lima Fiod, desenvolvedor PHP/Laravel com foco em back-end, APIs REST e aplicações full stack.

## Estrutura

```text
portfolio/
├── assets/                 # Currículo e arquivos públicos
├── css/
│   ├── base.css            # Temas, reset e utilitários
│   ├── components.css      # Navegação, botões, modal e componentes
│   ├── sections.css        # Hero, projetos, trajetória e contato
│   └── responsive.css      # Responsividade e acessibilidade
├── js/
│   ├── data/projects.js    # Conteúdo dos projetos
│   ├── modules/            # Recursos independentes da interface
│   └── main.js             # Inicialização da aplicação
└── index.html
```

## Executar localmente

Como o JavaScript usa módulos ES, execute o projeto por um servidor HTTP local. Por exemplo:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
